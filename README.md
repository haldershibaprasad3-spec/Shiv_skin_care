# Shiv Skin Care Website

A responsive skincare landing page with a dramatic red dragon hero, crimson styling, animated details, product cards, routine guide, journal section, and newsletter demo.

## Files
- `index.html` — website content and structure
- `style.css` — responsive styling and animations
- `script.js` — mobile navigation, demo shopping bag, reveal effects, and newsletter message
- `assets/hero-dragon.png` — generated dragon hero artwork, if included

## Preview
1. Extract `shiv-skin-care_website.zip`.
2. Keep the HTML, CSS, JavaScript, and `assets` folder together.
3. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.

## Notes
The product content is sample content. The bag is a front-end demo and checkout is not connected. The newsletter form does not send email until connected to an email service.
